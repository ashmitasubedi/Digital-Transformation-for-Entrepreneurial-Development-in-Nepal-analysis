3. Stationarity Tests: ADF, Phillips-Perron & KPSS¶

Three tests are used together because ADF and PP (H0 = unit root) can disagree with KPSS (H0 = stationary) in small samples — running all three gives a more reliable read on the order of integration than any single test.

In [7]:
def adf_test(series, name):
    series = series.dropna()
    if len(series) < 10:
        return {"ADF Statistic": np.nan, "ADF p-value": np.nan}
    result = adfuller(series, autolag='AIC')
    return {"ADF Statistic": round(result[0], 3), "ADF p-value": round(result[1], 3)}

def pp_test(series, name):
    series = series.dropna()
    if len(series) < 10:
        return {"PP Statistic": np.nan, "PP p-value": np.nan}
    result = PhillipsPerron(series)
    return {"PP Statistic": round(result.stat, 3), "PP p-value": round(result.pvalue, 3)}

def kpss_test(series, name):
    series = series.dropna()
    if len(series) < 10:
        return {"KPSS Statistic": np.nan, "KPSS p-value": np.nan, "KPSS 5% Critical": np.nan}
    try:
        stat, p, lags, critical = kpss(series, regression='c', nlags='auto')
        return {"KPSS Statistic": round(stat, 3), "KPSS p-value": round(p, 3),
                "KPSS 5% Critical": critical["5%"]}
    except Exception:
        return {"KPSS Statistic": np.nan, "KPSS p-value": np.nan, "KPSS 5% Critical": np.nan}

def interpret(row):
    adf, pp, kpss_p = row["ADF p-value"], row["PP p-value"], row["KPSS p-value"]
    if pd.isna(adf):
        return "Insufficient Data"
    if (adf < 0.05) and (pp < 0.05) and (kpss_p > 0.05):
        return "Stationary"
    elif (adf > 0.05) and (pp > 0.05) and (kpss_p < 0.05):
        return "Non-Stationary"
    else:
        return "Mixed Evidence"

def run_stationarity(variables, data):
    results = []
    for var in variables:
        row = {"Variable": var, "Transformation": "Level"}
        row.update(adf_test(data[var], var))
        row.update(pp_test(data[var], var))
        row.update(kpss_test(data[var], var))
        results.append(row)

        row = {"Variable": var, "Transformation": "First Difference"}
        row.update(adf_test(data[var].diff(), var))
        row.update(pp_test(data[var].diff(), var))
        row.update(kpss_test(data[var].diff(), var))
        results.append(row)

    out = pd.DataFrame(results)[
        ["Variable", "Transformation", "ADF Statistic", "ADF p-value",
         "PP Statistic", "PP p-value", "KPSS Statistic", "KPSS p-value", "KPSS 5% Critical"]
    ]
    out["Conclusion"] = out.apply(interpret, axis=1)
    return out

Interpretation guide: ADF/PP p < 0.05 → reject unit root → stationary. KPSS stat above its 5% critical value → reject stationarity → non-stationary. A variable is I(1) if it's non-stationary in levels by ADF/PP but becomes stationary after first-differencing (and KPSS agrees). Nepal's digital-transformation variables typically show strong trending I(1) behavior, while NBD and the macro variables are closer to I(0) — a mix consistent with ARDL bounds testing (no I(2) variables required, unlike standard cointegration/VECM approaches).

6. Main Model — First-Differenced Short-Run Growth Model¶

bivariate ARDL bounds test (Section 7) indicates cointegration, the sample is too small (n=11) to treat that long-run relationship as reliable, so it is not used as the headline result. Instead the short-run relationship is estimated directly on first-differenced data: ΔNBD_t = β0 + β1·ΔDTI_t + ε_t

A full VAR is not used: with roughly 14 usable annual observations and only two series, a VAR(1) would consume too many degrees of freedom to be reliable. OLS on differenced data (the supervisor's stated fallback) is the appropriate choice at this sample size.

8. Granger Causality Test¶

Checks the direction of the relationship: does digital transformation lead entrepreneurship, or could causality run the other way (successful entrepreneurs adopting more technology)? Run on first-differenced series to satisfy stationarity.

In [16]:
gc_data = ts_full[["NBD", best_dim]].dropna().diff().dropna()

rows = []

11. CUSUMSQ Test (Variance Stability)¶

Exact critical bounds require the published Brown-Durbin-Evans (1975) tables; the diagonal line below is the expected path under stability — visual departures from it flag instability.

In [19]:
sq_resid = rresid_std[k - 1:] ** 2
cusumsq = np.cumsum(sq_resid) / np.sum(sq_resid)
x = np.arange(1, len(cusumsq) + 1)
expected = x / len(cusumsq)

plt.figure(figsize=(9, 5))
plt.plot(x, cusumsq, marker="o", linewidth=2, label="CUSUMSQ")
plt.plot(x, expected, "k--", linewidth=2, label="Expected Stability Path")
